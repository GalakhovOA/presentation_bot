# Salary Project Bot

Первая рабочая версия Telegram-бота, которая формирует сразу три персонализированных PDF на базе готовых макетов:

1. Для директора и бухгалтера: организация + ваш менеджер + зарплатный менеджер.
2. Для сотрудников: организация + зарплатный менеджер.
3. Буклет: исходные 5 страниц + отдельная 6-я финальная страница с организацией и зарплатным менеджером.

## Особенности

- При первом `/start` бот один раз запрашивает сохранённые контакты.
- На каждом контактном шаге есть кнопка `Не нужно`; тогда соответствующее поле хранится пустым и в PDF не печатается.
- При создании предложения бот спрашивает ИНН и название организации.
- После названия организации бот сразу отправляет 3 PDF.
- Контакты можно изменить через главное меню.
- PDF-макеты лежат в `templates/` и могут быть заменены при сохранении тех же размеров/композиции или после корректировки координат в `pdf_generator.py`.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env
# впишите BOT_TOKEN в .env
python bot.py
```

## Что лежит в templates

- `director.pdf` — исходный файл для директора/бухгалтера.
- `employees.pdf` — исходный файл для сотрудников.
- `booklet.pdf` — 5-страничный буклет.

## Важно для сервера

Если бот запускается через webhook/systemd, не меняйте генератор PDF: вместо `run_polling()` используйте вашу текущую webhook-конфигурацию в точке запуска. Остальная логика остаётся той же.

## Шрифты

На Ubuntu бот автоматически использует DejaVu Sans. На Windows он попробует Arial. Если шрифт находится в другом месте, задайте `FONT_PATH` и `FONT_BOLD_PATH` в `.env`. Файлы шрифтов в проект не включаются.
